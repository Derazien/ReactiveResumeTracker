## 🔄 How to Regenerate

To update all dependency graphs:

```bash
pnpm docs:maps
```

This will:
1. Generate DOT files for all graphs
2. Attempt to generate SVG files (skipped for very large graphs)
3. Output results to `docs/maps/`

**Time:** ~2-4 minutes depending on repository size

## 🛠️ Understanding the Graphs

### Node Colors (typical)
- **Blue**: Application entry points
- **Green**: Shared libraries
- **Yellow**: External dependencies
- **Red**: Potential circular dependencies

### Arrows
- **Solid**: Direct dependency
- **Dashed**: Indirect/transitive dependency

### Reading Tips
1. Start from app nodes (usually on the left)
2. Follow arrows to see what each module depends on
3. Look for clusters to identify cohesive modules
4. Red nodes or back-arrows indicate cycles (see ADR-0001)
