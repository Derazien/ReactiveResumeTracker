# Scratch Directory

> **WARNING: NON-AUTHORITATIVE CONTENT**

This directory contains temporary scripts, debug files, and experimental code. Do not rely on anything here for production use or documentation.

## Purpose

Workspace for temporary one-time-use scripts, debug/test SQL files, JSON snapshots, and migration artifacts.

## Structure

- temp-scripts/ - One-time automation and debug scripts
- migration/ - Database migration SQL and debug files
- data/ - JSON snapshots and test data

## Canonical Paths

For production scripts: scripts/
For documentation: docs/
For utilities: tools/

See docs/50-ops/Run-Paths-Catalog.md for canonical script inventory.
